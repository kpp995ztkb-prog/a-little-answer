# 实时摄像头水晶球体验

## 范围与视觉

第一版适配电脑浏览器，单页面完成摄像头授权、昵称输入、连续拉远、默想识别、点亮、睁眼揭晓和再次提问。不输入问题，不保存摄像头画面。三张参考图已提供：图 1 用于透明玻璃球、厚实边缘反光和深棕近黑的分层圆形底座；图 2 只用于柔和蜂蜜金色发光，不加入土星雕刻、木质底座或整球强光；图 3 用于舒展的衬线斜体镂空字形；2026-10-10 调整为无色半透明遮罩，去除彩色渐变与颗粒。中文赠语优先保证可读性，英文昵称可更明显使用衬线斜体。

全屏镜像摄像头按原比例裁切铺满。球内使用同一视频源，降低裁切倍率以呈现更多已有画面，加轻微曲面变形；不生成镜头之外的身体。文字单独绘制，不镜像。

开场半透明毛玻璃材质覆盖镜头，叠加细颗粒。赠语始终一行，赠语与昵称使用字形遮罩露出清晰镜头。真实输入控件负责键盘、中文输入法和焦点，字形遮罩同步昵称；去首尾空格，按 Unicode 字符限制 12 字，空白不可提交。昵称下方不显示辅助文案或确认按钮，仅按回车提交。

提交后用 3 秒连续缩小同一球体，球面赠语和球心昵称分开定位；昵称中心与球心完全一致。最终球固定中央偏下，底座进入画面。随后用 1 秒消退材质与赠语，保留玻璃及不发光昵称。长昵称按球内可用宽度缩小。

## 实现结构

采用浏览器单页面应用。三个职责：摄像头和球体渲染、识别观测、纯仪式状态转换。识别观测输出双手接近、胸前位置、眼睛开闭和观测有效性；动画只消费状态和时间。

推荐 Canvas 实时合成镜头、曲面与镂空，HTML 控件负责输入和操作。相比纯 CSS，多一层渲染管理但可准确实现实时字形镂空和球内重映射；完整 3D 引擎可以增强玻璃折射，但首版额外复杂度较高。

动作识别在浏览器本地进行。模型文件初始化失败时显示重试提示，摄像头拒绝、不可用时给出明确反馈；不以模拟摄像头冒充真实体验。

## 状态与时间

授权 → 输入 → 拉远（3 秒）→ 材质退去（1 秒）→ 等待姿势 → 点亮（1.5 秒）→ 等待睁眼 → 答案渐显（2 秒）→ 阅读 → 重置 → 等待姿势。

等待姿势阶段三条件连续满足 1.5 秒才触发：双手靠近或交握、双手在肩膀和躯干估算的胸前、双眼闭合。距离使用身体比例。无效观测或任一条件中断均清除连续保持时间，蓄光平滑消退。蓄光只作用于球缘。

触发时抽取答案并锁定本次仪式，不受后续手部姿势影响。昵称原位连续点亮，背景压暗但仍实时可见；粒子与薄雾保持克制。

触发后双眼有效观测为睁开且连续保持 0.4 秒，记录已睁眼。点亮尚未完成时缓存该记录，完成后揭晓。眼部观测丢失打断睁眼计时，不视作睁眼。持续闭眼无限等待。

答案位于昵称下方，昵称不移动。阅读时减弱粒子。60 条一至两行温柔文案，随机选择并排除上一条；昵称不影响抽取。

再次提问保留昵称，消退答案与光效，恢复亮度，清除锁定及所有计时和睁眼记录，回到引导。无需再次拉远。

## 验证

自动测试覆盖动作中断、单手、睁眼合手、头顶合手、短眨眼、触发只发生一次、点亮中提前睁眼、识别丢失、持续闭眼、重置清除记录和避免连续重复答案。

构建与浏览器验证检查页面加载、中文输入、空白限制、12 字限制、镜头比例、镂空随输入更新、昵称中心一致、动画连续和所有阶段操作。

真实摄像头验证需覆盖不同距离、明暗、眼镜和交握遮挡。无法实际验证的环境条件在交付时明确标记，不以自动测试代替实机结果。
